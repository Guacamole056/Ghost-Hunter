# Ghost Hunter project report

The AL-2002 Fall 2026 project report is available in two formats.

- [Full report (PDF)](Ghost_Hunter_Project_Report.pdf)
- [Editable report (Word)](Ghost_Hunter_Project_Report.docx)

The report covers the game design, HMM, implementation, experimental setup, three charts, testing, contributions and setup instructions. The two automated hunters captured the ghost in 100 and 51 of the 100 paired scenarios, respectively.

For the algorithm walkthrough, see [ALGORITHM_EXPLAINED.md](ALGORITHM_EXPLAINED.md). For installation, testing and PDF export, see the [README](../README.md).
